# Jillian Cung Communications Portfolio

A lightweight static portfolio designed for free hosting.

## Before publishing
1. Replace `YOUR-EMAIL-HERE` in `index.html`.
2. Replace placeholder project titles/copy with your selected work.
3. Add links to published articles.
4. Replace the video placeholder with an embedded YouTube/Vimeo video when ready.

## GitHub upload
Create a repository (for example `jillian-portfolio`) and upload `index.html`, `styles.css`, and `script.js` to the repository root.

## Render
Create a **Static Site**, connect the GitHub repository, leave the build command blank, and publish the repository root.
